# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 节点编辑（nodes 工具）

- **插入**：点击路径段，在该处插入节点，外形保持不变。
- **删除**：点击选中节点（Shift 多选）后按 `Delete`，可选择「尽量保持原曲线」或「保持相邻切线」，画布上实时显示新旧轮廓差异，确认后应用。
- **断开**：选中一个节点按 `B`——闭合路径在该处打开，开放路径拆成两条（样式与分组保留）。
- **连接**：选中两个开放端点（或两条开放路径）按 `J`——按实际方向处理控制柄；重合端点焊接为一个锚点，相距较远的端点用新线段桥接而不会移动。结果归属最上层路径的样式与分组；同一路径的两端相连则成为真正的闭合路径。
- 每次编辑都是一步撤销（↶），同时恢复当时的节点结构与选择。
